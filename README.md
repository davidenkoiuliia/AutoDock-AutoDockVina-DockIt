# AutoDock-AutoDockVina-DockIt
This repository contains data and scripts supporting the manuscript.
DOI: 10.5281/zenodo.24114601
# Contents
- 'DatabasePDBs' contains PDB files for complexes, proteins and ligands;
- 'DockIt_Inputs' contains input files for interactive docking;
- 'Molecular_docking' contains .pdbqt input files for automated docking and resulting docking conformations with output (arranged in folders by the PDB of complex and by docking programs, AD means AutoDock);
- 'MM-GBSA' contains inputs and outputs for MM-GBSA calculations (arranged in folders by the PDB of complex and by docking programs, AD means AutoDock, folders with no additional ending in its names consist DockIt files);
- 'Molecular_Dynamics.zip' contains input files for molecular dynamics of HIV- subtype F/HIV-1 subtype B - TL-3 complexes;
- 'Scripts' contains figures files and scripts that were used to build plots and figures.
# Code authorship and repository role
This repository contains data and computational materials supporting the results of the associated manuscript and represents the collective work of the study co-authors. The repository is maintained to ensure transparency and reproducibility of the published results.
