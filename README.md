# AutoDock-AutoDockVina-DockIt
This repository contains data and scripts supporting the manuscript.
# Contents
- 'DatabasePDBs' contain PDB files for complexes, proteins and ligands;
- 'DockIt_Inputs' contain input files for interactive docking;
- 'Molecular_docking' contain .pdbqt input files for automated docking and resulting docking conformations with output (arranged in folders by the PDB of complex and by docking programs)
